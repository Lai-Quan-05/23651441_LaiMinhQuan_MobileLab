# Chạy thử nhanh

Chạy npm start tại thư mục gốc, chọn tuần cần xem.

- Tuần 1: chọn lần lượt Bài 1 đến Bài 8.
- Tuần 2–3: xem giao diện nhà sách gốc.
- Tuần 5: chọn màu, bấm XONG để về chi tiết điện thoại.
- Tuần 6: tải phim, đổi danh sách/lưới, kéo tải lại.
- Tuần 7: màn hình chào → danh sách xe → chi tiết.
- Tuần 8: tải tour, tìm tên, xem nhóm theo thành phố và yêu thích.
- Tuần 9: xem sách, Counter, giỏ hàng, tài khoản.
- Tuần 10: chọn bài thêm bài viết hoặc bài CRUD.

Tuần 4 chờ đề. API, giao diện và logic các bài được giữ như code gốc; tính năng nào chưa có trong code gốc thì không thêm.
